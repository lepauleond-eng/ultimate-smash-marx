# Ultimate Smash Marx — VERSION TEST

> ⚠️ Version de test : des bugs sont possibles, tout peut encore changer.

Jeu de baston à 2 joueurs avec des militants marxistes (Lénine, Rosa Luxemburg).
Modes : **Brawl**, **Grève générale** et **École du Parti** (le tuto).

## Jouer dans le navigateur

👉 **https://lepauleond-eng.github.io/ultimate-smash-marx/jeu/**

Sur ordinateur, avec Chrome, Edge ou Firefox (récents). Le premier chargement prend quelques secondes (~45 Mo).
Sur un PC portable avec deux cartes graphiques, le jeu est plus fluide si le navigateur utilise la carte puissante (Windows : Paramètres > Affichage > Graphiques > choisir le navigateur > « Hautes performances »).

## Jouer sur Windows

Télécharge `UltimateSmashMarx-test-windows.zip` dans les [Releases](https://github.com/lepauleond-eng/ultimate-smash-marx/releases),
dézippe, puis lance `UltimateSmashMarx.exe`.
Windows peut afficher « Windows a protégé votre ordinateur » : clique sur « Informations complémentaires » puis « Exécuter quand même ».

## Commandes

| | Joueur 1 | Joueur 2 |
|---|---|---|
| Bouger | ZQSD | Flèches |
| Attaquer | F | Pavé numérique 1 |

Manettes acceptées. Échap (ou Start) : retour au menu. J2 peut être joué par l'IA.
